# Central Skills 仓库全选与工具栏对齐

用户希望在选中仓库后能直接一次选齐技能，同时让更新模式、排序和视图与搜索框对齐。用户已确认实施本轮对话给出的优化计划。

## 验收

- 宽窗口搜索输入与三个控件的垂直中心相差最多 2 CSS px。增加、移除或换行筛选标签时，第一行保持稳定。900 CSS px 宽窗口无页面横向溢出，工具成组换行。
- 从侧栏打开具体仓库，零勾选时在仓库标签旁看到中英文带数量的全选操作。部分勾选可补齐，全选后同处可清空，空结果禁用。
- 搜索、标签和安装状态等筛选缩小结果时，数量及选择跟随实际匹配项，涵盖虚拟列表中未滚到的条目。更换仓库后不会残留不可见的勾选。
- 全选只改变选择；批量安装仍通过现有操作栏和目标确认对话框，最终请求仅包含选中的技能及目标。保留仓库外现有的手动选择和批量操作。

## 追加验收：本地安装

用户在交付验证时报告 Windows 的 just install 长时间停在 beforeBundleCommand，并要求修复。要求主构建完成后直接进入打包，安装目录同时包含此次构建的桌面程序和可运行的 CLI。独立 pnpm build:cli 仍可使用。
