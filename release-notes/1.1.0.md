# SkillPort 1.1.0

### English

SkillPort 1.1.0 is a visual release. It replaces the Catppuccin console look
with the Light Glass design language across every page, adds Glass Light and
Glass Dark themes, and uses the Windows 11 Mica window material. Routes, data,
and behavior are unchanged.

#### Highlights

- New Light Glass interface: translucent panels over a calm mint-to-lavender
  canvas, pill buttons and tags, large rounded corners, and thin line icons.
- Two semantic accents only: mint marks completed work, inputs, and primary
  actions; lavender marks outputs and secondary data, often as light tinted
  blocks.
- Glass Light and Glass Dark themes, switched from the sidebar footer or
  Settings → Appearance. Both pass WCAG 2.1 AA contrast on the translucent
  surfaces as they are actually composited.
- Windows 11 Mica window material, on by default. The window starts opaque and
  becomes translucent only after Mica is applied, so there is no transparent
  or white flash.
- Dashboard, Skill Usage, and the observability console use large-number stat
  tiles; skill cards, dialogs, menus, drawers, and toasts share one set of
  glass components.
- Real background blur is limited to sticky bars and overlays to keep large
  libraries scrolling smoothly in WebView2.

#### Breaking changes and migration

- **Themes:** Catppuccin (Latte, Frappé, Macchiato, Mocha), Claude Light and
  Claude Dark, and the 14 accent colors are removed. On the first launch after
  upgrading, the saved theme migrates once: Latte and Claude Light become Glass
  Light; Frappé, Macchiato, Mocha, and Claude Dark become Glass Dark. The saved
  accent is discarded. Without a saved theme, SkillPort follows the system
  light or dark setting.
- **Body font:** the default body font is now Geist (sans-serif). JetBrains
  Mono stays for code, paths, IDs, and key caps. On upgrade, a body font that
  is still the old default (JetBrains Mono, with no custom font) switches to
  Geist once. A custom body font is kept. You can change it back in
  Settings → Appearance → Typography.
- **Window material:** Mica is on by default on Windows 11 and can be turned
  off in Settings → Appearance → Window material. Windows 10 does not support
  Mica and keeps an opaque gradient background. Mica turns to a solid color
  while the window is inactive; this is Windows behavior.
- The light / dark switch moved from the top bar to the bottom of the sidebar.

- Linux packages are published as install artifacts, not as built-in updater
  targets.

### 中文

SkillPort 1.1.0 是一次视觉版本：所有页面从 Catppuccin「调度台」风格换成「轻盈
毛玻璃」设计语言，新增浅色玻璃与深色玻璃两套主题，并在 Windows 11 上使用 Mica
窗口材质。路由、数据与行为保持不变。

#### 亮点

- 全新轻盈毛玻璃界面：柔和的薄荷到薰衣草 canvas 上叠半透明面板，按钮与标签
  胶囊化，统一大圆角与细线图标。
- 只保留两个语义强调色：薄荷表示完成、输入与主操作；薰衣草表示输出与次要数据，
  常以极浅底色区分信息块。
- 浅色玻璃 / 深色玻璃两套主题，可在侧栏底部或 设置 → 外观 切换；两套主题均按
  半透明表面实际合成后的颜色通过 WCAG 2.1 AA 对比度校验。
- Windows 11 默认启用 Mica 窗口材质。窗口先以不透明背景启动，Mica 应用成功后
  才变通透，不会出现透明穿透或白闪。
- Dashboard、技能使用与可观测性控制台改用大号数字 StatTile；技能卡、对话框、
  菜单、抽屉与通知共用同一套玻璃组件。
- 真实背景模糊只用于 sticky 条与浮层，保证大型技能库在 WebView2 中滚动流畅。

#### 不兼容变更与迁移

- **主题**：移除 Catppuccin（Latte、Frappé、Macchiato、Mocha）、Claude 亮色与
  Claude 暗色主题，以及 14 种强调色。升级后首次启动会一次性迁移已保存的主题：
  Latte、Claude 亮色 → 浅色玻璃；Frappé、Macchiato、Mocha、Claude 暗色 → 深色
  玻璃。已保存的强调色会被丢弃。没有保存主题时跟随系统明暗。
- **正文字体**：正文默认字体改为无衬线字体 Geist，JetBrains Mono 只用于代码、
  路径、ID 与按键。升级时如果正文字体仍是旧默认值（JetBrains Mono 且没有自定义
  字体），会一次性改为 Geist；已自定义的正文字体保持不变。可在 设置 → 外观 →
  字体 改回。
- **窗口材质**：Windows 11 默认开启 Mica，可在 设置 → 外观 → 窗口材质 关闭。
  Windows 10 不支持 Mica，保持不透明的渐变背景。窗口失去焦点时 Mica 会变成纯色，
  这是 Windows 的系统行为。
- 明暗切换从顶栏移到了侧栏底部。
